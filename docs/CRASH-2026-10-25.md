## Changes

- Bound snapshot-driven native tray work through UI acknowledgements; callbacks read latest state instead of queueing obsolete snapshots indefinitely. Timer catch-up ticks are skipped.
- Cache unchanged tray tooltips, retain the 15-second registration health probe, and honor failed-probe backoff even during snapshot bursts. Changed glyph/theme/preferences still apply immediately when the shell accepts them.
- Release tray diagnostic and settings watch guards before native window/COM operations. Tray reconciliation refuses recursive locking. Show/focus releases the motion mutex before dispatching focus callbacks.
- Add a separate **in-process** UI heartbeat. Only one callback is outstanding. After 30 seconds without acknowledgement it writes a durable warning; after 120 continuously observed seconds it writes the active native stage and exits 1 for the existing task's failure policy. Suspend/scheduling gaps get a fresh grace period. Native menu/move loops and owned-dialog holds are exempt. No second process, repeating launcher, task-policy change, or production debugging port was added.
- Add direct, synced `logs/failures.log` output for fatal panics/startup errors/hang failures. Panic source location/backtrace is retained, but potentially sensitive panic payloads are deliberately omitted. Log desktop start/intentional exit normally. Stop the heartbeat before intentional exit and bound engine shutdown to ten seconds, retaining successful intentional-exit semantics.

These are confirmed resilience/diagnostic improvements, not proof that one specific repaired path caused the historical incident. The heartbeat monitors native dispatch, not all possible provider/renderer failures, and only a task-owned process receives Task Scheduler recovery.
